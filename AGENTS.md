## How to treat existing code

This started out as a MVP prototype. Only things listed in DECISIONS.md are 
safe to assume to be intentional. Everything else (layout, placement, styling, 
copy, navigation, flow order,  etc.) may well be a placeholder, chosen arbitrarily. 
So don't treat these things as "set in stone", always consider refactoring to
improve the state overall, and don't hesitate to propose changes.
